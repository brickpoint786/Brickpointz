# Brickpointz → BrickPoint WordPress Theme

This repository contains the **BrickPoint** construction/bricks website as a
production-ready, installable **WordPress theme** (converted from the original
Next.js source), plus the preserved original source archive for reference.

## Contents

| Path | Description |
|---|---|
| `brickpoint/` | Installable WordPress theme — zip this folder to `brickpoint.zip` and upload via **Appearance → Themes → Add New → Upload** |
| `brickpoint.zip` | Ready-to-upload theme package (built from `brickpoint/`) |
| `docs/README.md` | Full setup, Elementor, WooCommerce & import documentation |
| `brickpoint-construction-company-website.zip` | Original Next.js source (reference, preserved) |

## Quick Start

1. Upload `brickpoint.zip` → **Appearance → Themes → Add New → Upload Theme** → Activate.
2. Install & activate **Elementor** + **WooCommerce**.
3. **Appearance → BrickPoint Setup** → **Import BrickPoint Demo Content**.
4. **Settings → Permalinks** → Save.

See [`docs/README.md`](docs/README.md) for complete documentation.
