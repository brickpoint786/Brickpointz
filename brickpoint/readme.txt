BrickPoint — SS7 Bricks & Construction Materials. Production-ready WordPress theme with Elementor Theme Builder integration and WooCommerce support, faithfully converted from the BrickPoint Next.js website.

== Description ==

BrickPoint represents Masha Allah Bricks Company and Fine Bricks Company — supplying SS7 branded bricks and construction materials. This theme recreates the original website's design (layout, colors, typography, sections, WhatsApp ordering, locations, projects, blog, responsive behavior) as a native WordPress theme.

Features:

* Elementor-ready (edit pages visually; Theme Builder header/footer/single/archive with Elementor Pro)
* 6 custom Elementor widgets (WhatsApp button, section heading, locations, categories, CTA banner, feature cards)
* WooCommerce integration (14 product categories, price-on-request, SS7 badges, WhatsApp ordering)
* Locations + Projects custom post types with Elementor support
* Branded templates for Home, About, Products, SS7 Bricks, Projects, Locations, Blog, Contact, 404, Search
* Centralized company settings (Customizer > BrickPoint Settings)
* One-click demo content import (Appearance > BrickPoint Setup)

== Installation ==

1. Upload `brickpoint.zip` via Appearance → Themes → Add New → Upload Theme.
2. Activate the theme.
3. Install & activate Elementor and WooCommerce.
4. Go to Appearance → BrickPoint Setup → Import BrickPoint Demo Content.
5. Assign menus (Appearance → Menus) if needed; homepage/blog are assigned automatically.

See docs/README.md for full documentation.
